Dure Installer helps small shop owners deploy, configure, and manage the infrastructure for a Mycart e-commerce backend.

<b>Infrastructure Management</b>
• Create and manage Google Compute Engine virtual machines
• View GCP status and billing information
• Manage DNS zones and records with Cloudflare, Google Cloud DNS, DuckDNS, and Porkbun
• Manage SSH hosts and run remote operations
• Configure security components including firewall rules and fail2ban-rs

<b>Store Operations</b>
• Monitor Mycart service health and store statistics
• Fetch remote application logs
• Inspect and manage scheduled jobs
• Deploy and manage Mycart and Prosody installations

<b>Security and Storage</b>
• Profile-scoped configuration and data
• Cryptographic identity and GitHub Sigstore attestation support
• Secure key storage using the platform keyring where available
• Pure-Rust TLS and SSH components with no OpenSSL dependency

<b>Architecture</b>
Dure Installer is a native Rust application using egui and eframe for its Material3-style interface. Operations are coordinated through an actor-based ViewModel and the smol async runtime, with Diesel for local database storage.

The same project provides desktop clients for Linux, macOS, and Windows, plus headless CLI builds. WASM targets provide the guest and store-front experience. The customer shopping client is maintained separately as dure-sijang.
