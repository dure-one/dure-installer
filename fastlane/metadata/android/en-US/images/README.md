# Listing Images

`icon.png` is the current 512×512 Android listing icon.

The other logo files in this directory are source or auxiliary branding assets:

- `logo.svg`: vector source
- `logo110.png`: 110×110 raster logo
- `logo1024.png`: 1024×1024 raster logo

Optional store artwork may be added when available:

- `featureGraphic.png`: preferred 1024×500 (or 512×250)
- `phoneScreenshots/`: current Android screenshots in the store's accepted dimensions
- `promoGraphic.png`: 180×120 promotional image, if required by the target store
- `tvBanner.png`: 1280×720, only if Android TV is actually supported

Screenshots and promotional artwork should show Dure Installer's actual infrastructure,
DNS, SSH, security, and store-management workflows. Do not show the separate
customer-shopping client (`dure-sijang`) or unsupported Firebase, Supabase, Cafe24,
WebSocket server, or payment workflows.
